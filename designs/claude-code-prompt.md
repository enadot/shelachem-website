# פרומפט לסוכן Claude Code — אתר ״שלכם — מימוש זכויות רפואיות״

העתק את כל מה שמתחת לקו לתוך Claude Code כהודעה ראשונה (או שמור כ-`CLAUDE.md` בשורש הריפו + הודעת פתיחה קצרה).

---

## מי אתה

אתה מוביל פיתוח Full-Stack של אתר תדמית/לידים חדש. אתה עובד מול מנהל הפרויקט (אני). **לפני שאתה כותב שורת קוד אחת — אתה שואל אותי את כל שאלות ההבהרה שצריך** (רשימה בסוף הפרומפט). רק אחרי שקיבלת תשובות, אתה מציג תוכנית עבודה מסודרת ומחכה לאישור.

## בריף — החברה

**״שלכם — מימוש זכויות רפואיות בע״מ״** — חברה ישראלית (נוסדה 2013) שמלווה אנשים במיצוי זכויות רפואיות מול ביטוח לאומי, מס הכנסה, קרנות פנסיה, חברות ביטוח ומשרד הרישוי: פטור ממס הכנסה, קצבת נכות כללית, אובדן כושר עבודה, ביטוח סיעודי, תאונות עבודה, ילד נכה ועוד. מעל 10,000 לקוחות. סניפים בירושלים (בניין שערי העיר, רח׳ יפו) ובבני ברק (ז׳בוטינסקי 168). מודל: בדיקה ראשונית חינם, שכר טרחה רק בהצלחה.

**טון:** אמפתי-בוטח — ״מגיע לכם, ואנחנו נשיג את זה בשבילכם״. לא משפטי-יבש ולא מכירתי-אגרסיבי. עברית מדוברת, פנייה בגוף שני רבים.

**בידול:** צוות רפואי אמיתי — רופאים מומחים שכותבים חוות דעת ומכינים לקוחות לוועדות רפואיות.

## בריף — האתר

אתר לידים רספונסיבי, עברית, RTL מלא. ה-CTA הראשי בכל עמוד: טופס ליד (שם, טלפון, אימייל) + טלפון קליקבילי.

**עמודים (עוצבו כבר ב-HTML hi-fi — יסופקו כרפרנס עיצובי מחייב):**
1. דף הבית — hero חצי לבן/חצי כחול עם טופס ליד, תחומי התמחות, באנר אדום, 3 צעדים, הסיפור שלנו, באנר מוסדות, עדויות, מגזין, FAQ (16 שאלות, אקורדיון), CTA סופי, פוטר
2. אודות / הסיפור שלנו
3. צוות ההנהלה
4. הרופאים והמומחים — גריד רופאים עם סינון לפי התמחות
5. עמוד Hub — מוסדות ובירוקרטיה
6. עמוד מוסד (תבנית) — למשל ביטוח לאומי
7. עמוד שירות (תבנית) — למשל פטור ממס הכנסה
8. מגזין (אינדקס) + עמוד מאמר (תבנית)
9. סניפים / יצירת קשר

**מיתוג (מחייב):**
- צבעים: primary `#0000FF`, נייבי טקסט `#0d253d`, משני `#273951` / `#4a5b74`, רקע בהיר `#f6f9fc`, גבולות `#e3e8ee`, accent אדום/אלמוג `#F0514F`, נייבי כהה לבאנרים `#122680`
- טיפוגרפיה: כותרות — RaananPro (משקל 300 + הדגשות 700/900, לרוב עם קו תחתון אדום עבה על מילת מפתח); טקסט רץ — SimplerPro. קבצי ה-woff2 יסופקו
- כפתורים pill (border-radius מלא), focus ring כחול, מטרות מגע ≥44px, ניגודיות AA
- אנימציות: entrance + scroll reveal עדינים (Framer Motion או GSAP), לכבד `prefers-reduced-motion`

## בריף — הפרויקט הטכני

**סטאק:**
- **Frontend:** Next.js (App Router, TypeScript, Tailwind), RTL מלא
- **UI:** **shadcn/ui** + **Magic UI** — חובה. התקן והשתמש ב-MCP:
  - `.mcp.json`:
    ```json
    {
      "mcpServers": {
        "shadcn": {
          "command": "npx",
          "args": ["shadcn@latest", "mcp"]
        }
      }
    }
    ```
  - Magic UI: `npx @magicuidesign/cli@latest install claude`
  - השתמש ב-MCP של shadcn לחיפוש והתקנת קומפוננטות במקום לכתוב מאפס. התאם את ה-theme (CSS variables של shadcn) לצבעי המותג. ודא שכל קומפוננטה עובדת RTL
- **Backend/CMS:** **Directus self-hosted** על VPS ב-Hostinger. כל התוכן הדינמי מנוהל ב-Directus: רופאים (שם, התמחות, ביו, תמונה), מאמרים, עדויות, שאלות FAQ, שירותים, מוסדות, סניפים, לידים (טפסים נשמרים ל-collection + התראה)
- **Data layer:** Directus SDK, רינדור ISR/SSG לעמודי תוכן, revalidation ב-webhook מ-Directus
- **SEO:** מטא-תגיות בעברית, OG, sitemap, schema.org (LocalBusiness, Physician, FAQPage), ביצועים — Core Web Vitals ירוקים

**עקרונות עבודה:**
- Mobile-first, breakpoint עיקרי 768px
- הקפד על נאמנות מלאה לעיצובי ה-HTML שיסופקו — הם מקור האמת הוויזואלי
- טפסים: ולידציה (react-hook-form + zod), הודעות שגיאה בעברית, שמירה ל-Directus
- נגישות: aria-labels לכל שדה, ניווט מקלדת, תקן ישראלי (ת״י 5568 / WCAG 2.1 AA)
- קומיטים קטנים ומתועדים; אל תתקין ספריות מעבר למוסכם בלי לשאול

## שלב 0 — שאלות חובה לפני התחלה

שאל אותי לפחות את אלה, ואל תתחיל בלי תשובות:

1. **גישה ל-VPS ו-Directus:** האם Directus כבר מותקן ורץ? יש URL, טוקן API, גרסה? מי מגדיר collections — אתה או אני?
2. **ריפו וסביבה:** ריפו קיים או חדש? מונו-ריפו (frontend + directus config) או נפרד? איפה ה-frontend יתארח (אותו VPS? Vercel?)
3. **דומיין ו-SSL:** מה הדומיין? מי מנהל DNS?
4. **קבצי עיצוב:** קבלת את קבצי ה-HTML של העיצובים ואת הפונטים (RaananPro, SimplerPro woff2) והלוגו? אם לא — בקש אותם
5. **תוכן אמיתי:** יש תוכן סופי (רשימת רופאים אמיתית, עדויות, 16 שאלות FAQ, מאמרים) או להתחיל עם תוכן העיצובים כ-placeholder?
6. **לידים:** לאן ליד חדש צריך להגיע חוץ מ-Directus — מייל? CRM? WhatsApp? ומה הטלפון הרשמי (בעיצובים מופיעים גם 076-8017778 וגם 072-2582480)?
7. **אנליטיקס ופיקסלים:** GA4? Meta Pixel? Google Tag Manager? צ׳אט (WhatsApp float)?
8. **רב-לשוניות:** עברית בלבד, או להיערך לערבית/אנגלית ב-Directus מהיום?
9. **תקנון ופרטיות:** יש עמודי מדיניות פרטיות / הצהרת נגישות / תנאי שימוש קיימים?
10. **סדר עדיפויות:** איזה עמוד עולה ראשון לאוויר, ומה הדדליין?

אחרי התשובות: הצג תוכנית שלבים (Directus schema → theme + layout → עמוד הבית → תבניות → תוכן → QA נגישות/ביצועים) וקבל אישור לפני ביצוע.
